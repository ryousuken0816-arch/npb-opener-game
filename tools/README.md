# tools/

## compute_ratings.py — 能力値算出

```
python tools/compute_ratings.py --year 2008          # → generated/ratings/2008.json
```

`data/` のうち対象年以前の全年を入力に、対象年時点の能力値を算出する（標準ライブラリのみ）。
ロジックは docs/SPEC.md「能力値算出ロジック」。定数はすべてスクリプト冒頭にまとめてある。

### 算出の流れ

1. **成績の合算**: 1軍（players.json）と2軍（teamstats_linked.json）を直近3年 1.0/0.8/0.6 の加重で合算（Marcel方式）。
   2軍は1軍換算係数（例: 本塁打×0.70）を掛け、サンプル量は半分として数える
2. **少サンプル補正**: `w = min(1, サンプル / FULL)` で 観測値 と 事前値 を線形ブレンド。
   FULL は指標ごと（打率 400打席、BB% 200打席、FIP 450アウト=150回 など）。
   事前値は正規化母集団の30パーセンタイル（出場の少ない選手は平均以下が多いため）
3. **正規化**: 対象年から5年分の1軍シーズン（200打席以上 / 50回以上 / 守備は同一位置40試合以上）を母集団に z 値化
4. **スケール**: `55 + 15 × z` を 1〜100 に丸め、ランク S≥90 A≥80 B≥70 C≥60 D≥50 E≥40 F≥20 G<20

### 各能力の指標

| 能力 | 指標 |
|---|---|
| ミート | 打率 0.6 ＋ コンタクト率(1−三振/打数) 0.4 |
| パワー | ISO（塁打−安打）/打数 |
| 選球眼 | BB%（四球/打席） |
| 走力 | 盗塁企図率 0.45 ＋ 盗塁成功率 0.15 ＋ 三塁打率 0.4 |
| 肩力 | 守備位置別の 補殺/試合（捕手・三塁・遊撃・外野）※捕手は盗塁阻止率の暫定代替 |
| 守備力 | 守備位置別の失策率 ＋ ゴールデングラブ（当年+1.2σ, 1年前+0.9σ, 2年前+0.6σ, 3年前+0.3σ） |
| 投手 総合力 | FIP（定数 = 年ごとのリーグ防御率 − 素のFIP） |
| 投手 スタミナ | 1登板あたりアウト数（12以上で先発扱い。先発数がデータにないため） |
| 投手 特殊能力 | K/9・BB/9・HR/9 が母集団上位15%/下位15%で付与（50回未満は付与しない） |

### 未解決・要相談

- 捕手の肩力は盗塁阻止率がないため 補殺/試合 で代替（HANDOFF 既知の課題1）
- 投手総合力は FIP のみのため、救援投手が上位を占めやすい（先発/救援で別母集団にするか要検討）
- 守備成績もドラフト情報もない選手（2006年以前指名の未出場選手など）は `primary_pos: null`。全年データが揃えば解消する見込み
