## hub_menu_pawapuro.webp — ハブ画面（メニュー）

**真似したいところ**
- 左に縦並びの大きなメニューボタン（アイコン＋太字の文字、ボタンごとに色が違う）：試合へ／日程表／采配／新戦力／記録室／システム（「アイテム」は不要）
- 選択中のボタンが大きく・明るく強調される
- 下部に選択中メニューの説明文（例：「1・2軍入れ替え、オーダーや起用法の設定、練習の設定などをします。」）
- 右下に日付（年＋月/日＋曜日）を大きく表示
- 右側に順位表パネル（ページ送り付き）
- 上部中央にその時点のイベント名（「開幕戦」など）

**ユーザーの要望（2026-09-25）**
- **配色は選んだ球団ごとに変える**（球団カラーをテーマ色にする）
- **黒基調は見にくいので避ける**。明るく見やすい配色にする
- 3D（中央の選手キャラ・球場）は**まだ不要**

## schedule_pawapuro.webp — 日程表（早送り中の画面）

パワプロのペナントで日程を早送りしているときの画面。

**真似したいところ**
- 日付ごとの列を横に3日分並べる（「4月13日（月）」のような見出し）
- 各日に全カードをタイル表示：両チームのロゴ（または略称＋チームカラー）、試合後はスコア、試合前は球場名
- 試合のない日は「移動日」と大きく表示
- 自球団のカードや終わった試合は色を変えて区別する（終わった試合は暗め、これからの試合は明るい色）
- 上部に「〇月〇日（〇）終了まで早送り中」のような進行状況バー

- 右側にセ・パ両リーグの順位表（順位・チーム・ゲーム差）

**ユーザーの要望（2026-09-25）**

## draft_list_pawapuro.webp — ドラフト候補の一覧（ドラフト画面 → 1位指名の選択）

パワプロのドラフトで「第1巡選択希望選手」を選ぶ画面。

**真似したいところ**
- 左に候補のリスト：名前札（守備位置の色）・守備位置・出身・経歴（高校生／大学生／社会人）・年齢
- 他球団が指名済みの候補には「済」マーク
- 上部のタブで表示する項目を切り替え：情報／球速・コントロール・スタミナ（投手）／ミート・パワー・走力・肩力・守備力（野手）
- 「球団 ◀ 全選手 ▶」で絞り込み（全選手／ポジション別など）
- 右に選んだ候補の要約（球速・投法・適性・コントロール/スタミナのランク）
- 右上に候補の人数

**ユーザーの要望（2026-09-25）**
- **並び替え（ソート）機能は必須**：守備位置・経歴・年齢・各能力などで並び替えられるようにする
- 今の仕様に無い機能（契約金ポイントの残金・調査率・変化球の図など）は**無視してよい**

**設計上の注意**
- **候補の能力はそのまま見せる**（ユーザー決定 2026-09-25：史実の活躍選手はだいたい知っているので隠す意味が薄い）。アマ時代の活躍ニュースは SPEC どおり演出として表示
- 出身地（都道府県）は今のデータに無い（drafts.json は学校名のみ）。年齢は1軍出場のある選手しか生年月日が無い

**追加の要望（ユーザー 2026-09-25）：候補一覧に2つのランク（S〜G）を付け、並び替えもできるようにする**
- **当時の評価**：そのドラフト時点での有力度。史実の指名順位＋1巡目の競合数（`data/draft_first_round.json` の bids）から決める。例：2019年 佐々木朗希（4球団競合）→ S、山本由伸（2016年4位・高校生）→ C 前後
- **将来性（未来視）**：その選手の入団後の史実の活躍（ピーク時の能力）から決める。**ノイズあり**（CPU球団の指名判断と同じ「不完全な未来視」。ノイズの大きさは難易度設定）。例：山本由伸 → S（ただしノイズで A や B に見えることもある）
- 「当時の評価は低いが将来性は高い」＝お宝選手が一目で分かるようにする

**追加の要望（ユーザー 2026-09-25）：日程表から試合を進めたい** → 実装済み（HANDOFF.md 4.9）
- 日程表で日付を選んで「この日まで早送り」できるようにする（参考画像の「〇月〇日（〇）終了まで早送り中」＋「早送り中止」）
- 「1日進める」「1週間進める」も欲しい
- ハブ画面の「試合へ」（1か月まとめて）は近道として残す
- そのため進行を「月単位」から「日単位」に作り変える（SPEC の「月ごとの粒度」は、月替わりのイベント・育成コマンドのタイミングとして残す）
