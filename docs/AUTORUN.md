## ローカルで動かす場合（2026-10-03 追記：クラウドクレジットを使い切ったため）

- 作業フォルダはユーザーのPCの `C:/Users/user/Desktop/npb-opener-game`（GitHub の main と同じ）。作業ブランチを切って進め、終わったら main にマージして push する
- Godot は `C:/Users/user/Downloads/Godot_v4.7.2-stable_win64.exe/Godot_v4.7.2-stable_win64_console.exe`（Windows）。xvfb-run は無い
- テストは基本 `--headless` で流す。ウィンドウ付き（スクショを撮るテスト）は、画面上のマウス位置が操作に割り込んで偶然失敗することがあるので、先に PowerShell でカーソルを画面の端に移す：`Add-Type -AssemblyName System.Windows.Forms; [System.Windows.Forms.Cursor]::Position = New-Object System.Drawing.Point(0,0)`。それでも失敗したら1回だけ流し直す
- npb.jp などへのアクセスはローカルなら可能。データを足した場合は data/ に入れて HANDOFF.md に書く
- 使用量はクラウドクレジットではなく通常のプラン枠から減る。5時間枠の上限に当たったら、その時点の作業を終わらせて HANDOFF.md と表を更新してから止まる

## 進め方（毎回守る）

1. 作業を始める前に CLAUDE.md・HANDOFF.md・docs/SPEC.md を読む。前の作業のブランチが main にマージ済みか確認する
2. **1つの作業ごとに**：実装 → Godot 4.7 を起動してスクショ確認 → 既存のテストを全部通す（tactics_check・day_progress_check・pad_flow_check・player_detail_check・その他 tests/ にあるもの）→ その作業用のテストを追加 → main にマージして push → HANDOFF.md を更新して push → 下の表の「状態」を「完了」に書き換えて push
3. 会話（コンテキスト）を軽く保つため、調査や大きな実装はサブエージェント（Agent ツール）に任せ、本体は進行管理と確認に徹する
4. **ユーザーに聞きたいことが出たら止まらない**。無難な案を選んで進め、下の「あとで確認してほしいこと」に1行で追記する（何を選んだか・他の案は何か）
5. テストがどうしても通らない・壊れそうなときは、その作業を main にマージせずブランチに残し、理由を「あとで確認してほしいこと」に書いて次の作業へ進む
6. 全部終わったら、最後に HANDOFF.md の「次にやること」を更新して終了

### 5. ドラフト画面
docs/references/README.md の「draft_list_pawapuro.webp」とその下の追加要望、docs/SPEC.md の「ドラフト・編成」「UI/画面構成 → ドラフト画面」をすべて読んでから作る。オフの「ドラフト」段階に入る。
- **候補**：その年の史実のドラフト指名選手全員（`data/<年>/drafts.json` の当年秋の分。本指名と育成）。1軍出場のない選手も含める（能力は generated/ratings の仮IDの選手、または新人の初期能力の仕組みで作る）
- **今の「史実の新人をひとまず史実の球団に入れる」処理を置き換える**：ドラフトの結果で入団球団が決まる。自球団が指名しなかった選手は、CPU球団が指名する（指名されなかった候補は入団しない）
- **候補一覧**（参考画像のとおり）：名前札（守備位置の色）・守備位置・経歴（高校生／大学生／社会人・独立）・出身校・年齢（分かれば）。他球団が指名済みなら「済」。上部タブで表示項目を切り替え（情報／投手能力／野手能力）。右に選んだ候補の要約。**並び替えは必須**（守備位置・経歴・年齢・各能力・当時の評価・将来性）
- **2つのランク（S〜G）を付ける**：
  - 当時の評価：史実の指名順位＋1巡目の競合数（`data/draft_first_round.json`）から。例：佐々木朗希（2019年4球団競合）→ S、山本由伸（2016年4位・高校生）→ C 前後
  - 将来性（未来視）：入団後の史実の活躍（その後の年の ratings のピーク）から。**ノイズあり**（CPUの指名判断と同じノイズ。大きさは難易度設定の定数）
- **能力はそのまま見せてよい**（ユーザー決定）
- **進行**：開幕演出（簡単でよい）→ 1位入札（全球団同時。重複したら抽選。**抽選は2Dの演出でよい**、3D は不要）→ 外れたら再入札 → 2位以降はウェーバー（SPEC どおり、前年の順位で決める）→ 育成指名 → 結果まとめ。**自球団の指名は丁寧に、他球団の指名は早送り**（スキップも可）

- アマ時代の活躍ニュースはデータが無いので、今回は無しでよい（入れるなら「〇〇高の投手、最速〇km」程度の簡単な紹介文）
- コントローラー操作（長押しの連続移動を含む）に対応
- **デバッグ用の開始年選択**（ユーザーの要望：昔の選手はあまり知らないので、最近の年でドラフトを確かめたい）：タイトル画面で開始年を 2008〜2025 から選べるようにし（初期値は2008。デバッグ用と分かる控えめな表示でよい）、その年の所属・能力・日程で始める。さらに「すぐオフ（ドラフト）へ進む」ボタンかキー操作を用意して、シーズンを飛ばしてその年のドラフトを試せるようにする。2025年秋の新人は将来の成績がほぼ無いので将来性ランクが当てにならないことを画面か HANDOFF に書く
