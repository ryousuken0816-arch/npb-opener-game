# 能力の目盛りと、年ごとの点の入りやすさ（作業70・調査）

2026-11-03、担当N。ゲームのコード・能力値はまだ変えていない（調べただけ）。直し方はユーザーが下の案から選ぶ。

## まとめ

- **目盛り**：今の目盛り（規定打席・規定投球回クラスの平均＝63、1σ＝17）だと、打撃は「主力＝C〜D、控え・2軍＝D〜E」に分かれている。いちばん「みんな C」に見えるのは**守備力・肩**で、主力も控えも2軍も平均 58〜64（C）に集まっている。パワー・選球眼・守備は散らばり（SD 10〜11）がミート（15）より狭く、差が出にくい
- **試合の計算は z（平均からのずれ）しか使わない**（`SimPlayer.z_of`＝(値−63)/17）。目盛りの定数を `compute_ratings.py` と `SimPlayer` の両方で同じように変えれば、試合の結果は変わらない。ただし、能力の数値をそのまま使っている箇所（成長の係数、スタミナ→球数、架空の新人のひな形、Antigravity の新人の強化など）は全部そろえ直す必要がある
- **点の入りやすさ**：試合の計算は**どの年でも2008年の水準**（打率 .27・防御率 3.8 前後）になる。能力値は「その年の前5年の中での位置」なので、投高の年の「平均的な投手」も2008年の平均的な投手と同じように打たれる。2011年（飛ばないボール）は史実 3.01 → シミュ 4.1〜4.2、2025年は 3.01 → 3.7〜3.8
- **モイネロ**：能力値は 総合85（A）・K9 86・BB9 65・HR9 74 で妥当。ゲームでは2026年開始で防御率 2.98〜3.62（リーグ 3.74〜3.95）。リーグの水準が高すぎる分のほかに、**投手の能力の効き方が弱い**（シミュで K/9 7.4・HR/9 1.05、本人の実際は K/9 9.1・HR/9 0.54）

### 案

- **案1：年ごとの水準を史実に合わせる（おすすめ）**
  - `tools/` で年ごとに、史実のリーグの 三振%・四球%・本塁打/打席・インプレーの安打率（BABIP）から、2008年との差をロジットで出し、`generated/run_env.json`（年 → k・bb・hr・sharp のずれ）に書く。`game_sim.gd` は `BASE_*` にその年のずれを足す
  - 上の「2008年以外はさらに打高」の分が残るので、各年を2〜3回回して、リーグの打率・本塁打・防御率が史実の ±.005・±5%・±0.1 に入るまでずれを直す（ツールで自動）
  - 2011〜2012年の飛ばないボールは史実の数字に入っているので、そのまま反映される（本塁打が約6割に）
  - 2027年以降は、直近3年（2024〜2026年）の平均。2026年は三振 21.0% と極端なので、1年だけには合わせない
  - 試合の勝敗・個人成績の並びは変わらない（全員に同じだけ効く）。賞・記録・年俸の基準は数で見ているところがあるので、確認が要る（例：首位打者の打率、本塁打王の本数、`awards.gd`）
- **案2：投手の能力の効き方を強める**（案1と一緒に）
  - `A_K9_K`・`A_HR9_HR`・`A_CTL_BB` を、能力値のもとの成績（K/9・HR/9・BB/9 の散らばり）から合わせ直す。目安：モイネロ級（K9 z +1.35）で三振率 24〜25%、HR9 z +0.65 で被本塁打が 0.7倍ほど
  - 2008年の合わせ込み（`season_check` の個人成績の上位）とトップ投手の防御率（史実の上位は 1点台〜2点前半）で確かめる
- **案3：何もしない**：どの年も2008年の水準のまま（打率 .27、防御率 3.8）。モイネロは 3点前後
