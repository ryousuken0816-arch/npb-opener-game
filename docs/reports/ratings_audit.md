# 能力値の点検（作業39 第1段階）

ユーザーの声（2026-11-01）：「だいぶ能力感ぐちゃぐちゃやな」「佐藤輝明は今年最強選手なのにな」。
この資料は**点検だけ**（コード・能力値は変えていない）。方針が決まったら第2段階で直す。

## やり方

- ゲームの能力値：`generated/ratings/2026_pre.json`（2026年の開幕＝2025年までの成績で算出。2026年のゲームはこれで回る）。メジャーへ行った村上・岡本は `2025_post`、山本由伸は `2023_post`
- 実際の成績：`data/2025/`・`data/2026/` の `teamstats_linked.json`（npb.jp の1軍の打撃・投手・守備。2026年は最終成績）。wRC+・FIP・WAR はゲームの記録室（`godot/sim/records.gd`）と**同じ式**で計算した（実際の WAR は守備の指標が無いので守備得点なし）
- 表彰：`data/2025/awards.json`（ゴールデングラブ）と、成績から決まるタイトル。2025年の MVP・ベストナインはウェブで確認（出典は最後）。2026年の表彰は未発表
- 外部の指標（評判の物差し）：ユーザーが別の AI に集めてもらった CSV（tooldock の wRC+・WAR・FIP、DELTA（1.02）の2025年の UZR と内訳・2026年の WAR、ヌルデータ置き場の FIP）。数字は出典つきで 6.5 に引用し、CSV はリポジトリに入れていない（`python tools/ratings_audit.py ... --saber <CSV>` で読める）。2026年の守備位置ごとの UZR はまだ公開されていない（11月中旬の予定）
- ゲームで回した成績：`godot/tests/ratings_audit_dump.gd` で開始年を2026年・2025年にして公式戦を最後まで**10回ずつ**回し（1回約10秒）、`tools/ratings_audit.py` で平均した（自球団は阪神、CPU と同じ自動の采配）。作業33の資料 `docs/reports/2026_defense_war.md` は**1回だけ**の結果なので、たまたまの値が混ざっている（下の「資料の読み違い」）

## 1. 要点

いちばん大きい原因は次の3つ。

1. **守備力が「失策率」だけで決まっていて、守備範囲が入っていない**（算出の式）。試合では、その守備力が打球をアウトにする確率（範囲）にも失策にも効く。だから「エラーは少ないが範囲の狭い選手」が高く、「範囲は広いがエラーもある選手」が低く出る。牧（二塁 E49 → 2026_post で F39）、水野（遊撃 F38）、近藤（外野 A84）がその例。内野の「補殺/試合」（範囲の目安）は肩力として計算しているのに、試合では内野の肩は使っていない。**DELTA の2025年の守備範囲（RngR）と、ゲームの守備力の相関は 0.02**（64人）で、ほぼ無関係。牧は RngR +5.0 なのに E49、辰己は −11.6 なのに S95、岡林は −6.5 なのに A89、源田は −1.7・紅林は −2.7 なのに S95・S99。ただし npb.jp の (刺殺＋補殺)/試合 も RngR との相関は 0.08 しかなく、npb.jp の守備成績だけでは範囲はほとんど作れない（一塁〜三塁の補殺/試合だけは 0.5〜0.7）
2. **ほとんど守ったことのない位置にも、平均に近い守備力が付く**（算出の式＋自動のオーダー）。2軍で1試合守っただけの位置でも、少ないサンプルは「事前値」（母集団の30パーセンタイル目、ほぼC）に寄せるので C65 前後になる。記録が1つも無い位置だけが −2.5σ になる。そのため CPU の自動のオーダーが、清宮を二塁（2025年の二塁は2軍1試合だけ）、中村奨成を捕手（2023年に2軍で5試合）、内山壮真を捕手に入れる。外野は左・中・右の区別が無く「外野手」1つなので、近藤・筒香が中堅に入る
3. **能力値は3年の加重平均（1.0/0.8/0.6）なので、その年に化けた選手は出ない**（算出の式・仕様）。佐藤輝明は2025年に本塁打王・打点王・MVP だったが、2025年のゲーム（2024年までの成績）では wRC+ 129・WAR 4.2 にとどまり、上位10人に入らない。2026年のゲームでも wRC+ 159（実際 192、tooldock では 200）。ほかに、ゲームの試合では三振・四球・長打の差が実際より小さい（1シーズンの標準偏差：三振率 ゲーム .032／実際 .051〜.054、四球率 .019／.026、2026年の ISO .042／.075）

直し方の案（くわしくは5章）：

- 案A：守備力に守備範囲を入れる。npb.jp だけでは範囲が作れないので、DELTA の UZR（または評判）を元にした守備の評価を手で入れる（A'）か、npb.jp の補殺/試合（一塁〜三塁）とゴールデングラブを重くする（A、効きは限定的）
- 案B：守備の記録が少ない位置は、事前値を「その位置に不慣れ」側（低め）に置く。外野は中堅とそれ以外を分ける（または中堅は走力・守備範囲の高い選手だけ）
- 案C：試合での三振・四球・長打の効き方を強める（打者・投手とも）。必要なら直近の年の重みを上げる

## 4. 原因の見立て

### 4.1 データ（npb.jp の守備成績の粗さ）

- 守備成績は 試合・刺殺・補殺・失策・併殺 だけ。打球の方向・難しさが無いので、守備範囲は「(刺殺＋補殺)/試合」くらいしか作れない（投手の奪三振やゴロの多さで上下する）
- 外野は「外野手」1つで、左・中・右が分からない
- 捕手の盗塁阻止率が無い（肩力は補殺/試合で代用。既知の課題1）
- 補殺は年に数個〜十数個しかなく、外野の肩（補殺/試合）は1年ではほとんど偶然
- DELTA の2025年の RngR と npb.jp の守備成績（同じ位置・40試合以上の z）の相関：(刺殺＋補殺)/試合 は全体 0.08（遊撃 −0.21・外野 0.04）、補殺/試合 は 一塁 0.68・二塁 0.51・三塁 0.50・遊撃 0.03・外野 0.18、失策率は −0.09。人数が少ない（位置ごと9〜24人）ので目安だが、**npb.jp の数字から範囲を作るのは一塁〜三塁の補殺以外ほぼ無理**

### 4.2 算出の式（`tools/compute_ratings.py`）

- **守備力＝失策率（＋ゴールデングラブの加点）だけ**。2025年の能力値と実際の成績の相関：守備力と失策率 0.42〜0.76、守備力と RF は 二塁 0.11・遊撃 0.06・捕手 −0.03（範囲が入っていない）
- 内野（三塁・遊撃）の「肩力」は補殺/試合で、中身は守備範囲に近い（遊撃の肩力と補殺の相関 0.89）。でも試合では内野の肩は使われない（4.4）
- **少サンプル補正の事前値が「平均よりやや下」で、守ったことのない位置にも付く**。記録が1つでもある位置は守備力 C 前後（清宮の二塁 C65＝2軍1試合、中村奨成の捕手 C61＝2軍5試合、福永の遊撃 C63＝0試合の記録あり）。記録が無いと −2.5σ（試合での不慣れ）なので、「1試合」と「0試合」で大きく違う
- 肩力の少サンプル補正の満点が60試合（`FULL_CHANCES["arm"]`）で、補殺のような少ない事象には短すぎる → 中山礼都 S100、西川史礁 S100
- **3年の加重平均（1.0/0.8/0.6）と規定の母集団**：予想としては妥当だが、化けた年がすぐには出ない（佐藤 2025年、栗原・森下・山口航輝の2026年）
- ミート＝打率0.6＋コンタクト率0.4：三振の多い強打者（佐藤）は D になりやすい
- 投手の役割（先発/救援）は前年までの1登板あたりのアウト数（平良の先発転向は2026年のうちは出ない）

### 4.3 正規化の目盛り（63＋17z、1〜100）

- レギュラー級（加重の1軍打席900以上、45人）のランク：ミート S2・A7・B15、パワー S1・A5、選球眼 S1・A4、守備 S5・A10、肩 S0・A2。**トップがS・Aに届かないほどの圧縮は無い**。デプスの「現在の能力」も S1（近藤）・A5（佐藤・岡本など）・B19・C20
- ただし**100で頭打ち**：パワーは 岡本・村上・筒香・佐藤（97）が 97〜100 に並び、村上（ISO .39）と佐藤（.30）の差が消える。選球眼も 近藤・村上 が100、走力は100が25人（主に控え）
- ドラフト画面の「1年目」の総合（`Draft.FIRST_BAT_WEIGHTS` の重みつき平均）は z が平均で縮むので、C 帯に集まる（重みつき平均を 63＋17z に置くと レギュラー45人のうち C が32人）。表示だけの問題

### 4.4 試合のシミュレーションでの効き方（`godot/sim/game_sim.gd`）

- **守備の能力値は試合にほぼそのまま出る**：守備得点（10回の平均）と能力値の守備力の相関は 二塁 0.99・遊撃 0.96・三塁 0.94・中堅 0.90。つまり守備のずれはほとんど能力値（4.2）のせいで、試合の式のせいではない
- 1シーズンの偶然は大きい：同じ選手を回し直したときの守備得点の標準偏差は 6〜8点で、選手の間の差（3〜9点）と同じくらい（右翼は偶然 7.9 ＞ 差 3.1）。作業33の資料の「近藤の肩 +15.7」「佐藤の三塁 −8.7」はこの偶然
- 外野の肩は「本塁を狙える走者」の機会を、単打・二塁打・犠飛の種類を分けずに1つの平均と比べている。機会の種類の割合でぶれる
- **三振・四球・長打の差が実際より小さい**：1シーズンの標準偏差（400打席以上）で 三振率 ゲーム .032／実際 .051〜.054、四球率 .019／.026〜.027、ISO .042〜.048／.052（2025年）・.075（2026年）。投手の K/9 は ゲーム 0.96／実際 1.30〜1.48。打率の差はゲームのほうが大きい（.030／.022）。打者の wRC+ は1回ごとのばらつきなら実際と同じくらい（ゲーム 24〜27／実際 21〜27）だが、才能の差より偶然の分が多い（2025年の実際との相関 0.55、2026年 0.70）
- **リーグ全体の打撃の水準が2008年に合わせてある**（作業4.8で2008年の史実に合わせた係数）：1チーム1試合の得点 ゲーム 4.06〜4.09／実際 2025年3.29・2026年3.59、本塁打 ゲーム 約1450本／実際 2025年1096本。リーグの打率は実際 .240〜.244。投手の防御率がゲームでは全体に高い（村上頌樹 3.12、実際 1.85）
- 投手の WAR の上位はゲーム 3.0〜3.8、実際（同じ式）3.5〜4.9 で、大きな差はない。野手の WAR の上位（ゲーム 7〜8）は守備位置（中堅・捕手）と守備得点で上がっている

### 4.5 CPU の自動のオーダー（`godot/sim/sim_team.gd`）

- スタメン＝打力＋守備力×位置の重み（捕手0.9・遊撃0.8・二塁0.6・中堅0.6・三塁0.4…）を、捕手→遊撃→二塁→中堅→三塁→左翼→右翼→一塁 の順に貪欲に埋めて、入れ替えで改善
- 守備力は4.2の「記録が少しでもあれば C」なので、打撃の良い選手が難しい位置に入る（清宮→二塁、中村奨成・内山→捕手、郡司→三塁）
- 中堅は「外野手」の守備力＋走力×0.3 で選ぶ。中堅の経験は見ていない（近藤・筒香・中川圭太・松本剛が中堅）
- 史実でどの位置を守ったか（2026年の実際の起用）は使っていない。開幕時の能力値（3年平均）だけで組むので、実際の正選手（西川史礁・水野・宗山など）が控えになる

## 5. 直し方の案

| 案 | 中身 | 直るもの | 影響の大きさ | ほかに壊れそうな所 |
|---|---|---|---|---|
| **A. npb.jp の数字で範囲を足す** | `compute_ratings.py` で一塁〜三塁は 補殺/試合 を範囲として守備力に足す（例：範囲0.5・失策0.5）。遊撃・外野は npb.jp では範囲が作れない（RngR との相関 0.0〜0.2）ので失策率と GG のまま | 一塁〜三塁の一部（牧など） | 大（全年の能力値を作り直し）。効きは限定的 | 2008〜2028年の能力値・成長の係数（`growth_coefficients.py`）・架空選手のひな形（`fictional_draft.py`）を作り直す。投手のゴロ率で RF が上下する（チームの投手で補正するとよい）。セーブのデータは能力値を持っているか要確認 |
| **A'. 外部の守備の評価を入れる** | DELTA の UZR（または評判）を元にした選手ごとの守備の評価（例：位置ごとに S〜G、年ごと）を手で表にして、守備力に重く混ぜる。UZR の数字そのものはリポジトリに入れず、ランクだけ持つ | 牧・辰己・岡林・源田・紅林・西川史礁など、範囲の評価全般 | 大（表づくりの手間。2008年からの全年は無理なので、UZR の無い年・選手は今の式） | DELTA の利用条件（ランクに直しても出典の扱いに注意）。表の無い年と有る年で守備力の付き方が変わる |
| **B. 守ったことの少ない位置は低めに** | 守備の事前値を位置ごとに「不慣れ」（例：記録なしの −2.5σ と、満点のサンプルの間を線形に）に変える。肩の満点のサンプルを60試合→200試合くらいに。外野は「中堅」の経験（npb.jp に無いので、外野手の中で範囲・走力が上位の選手だけ中堅可にする、など）を足す | 清宮の二塁、中村奨成・内山の捕手、近藤・筒香の中堅、中山礼都の肩 | 中（能力値の作り直しは必要。オーダーの式はそのまま） | 本当にコンバートした選手（2026年の佐藤輝明の外野など）が低く出る。ゲームで自分で位置を変えたときの守備がかなり下がる |
| **B'. オーダーで史実の位置を優先** | `SimTeam._starter_score` で、その年（または前年）の史実の守備位置の試合数に加点。CPU は史実に近い位置に入る | 位置のずれ全般、森友哉の捕手固定 | 小〜中（Godot だけ） | 2027年以降（史実が無い年）は前年の位置を使う。自球団の「自動で組む」も変わる |
| **C. 試合で三振・四球・長打の差を広げる** | `game_sim.gd` の A_MEET_K・A_K9_K・A_EYE_BB・A_CTL_BB・A_POW_HR などを大きく（三振率の標準偏差 .032→.05 が目安）。ミートを「打率」と「コンタクト（三振）」に分けて試合に渡すと、佐藤のような打者が正しく出る | 佐藤・村上・岡本のような強打者、奪三振の多い投手 | 中（係数の調整と、`season_check.gd` でリーグ全体の平均を合わせ直す） | 打率・防御率のリーグ平均が動く。能力値に「コンタクト」を足すなら compute_ratings と画面も変わる |
| **C'. リーグの水準を年ごとに** | リーグ全体の打撃（安打・本塁打の基準の率）を史実の年ごとの値に合わせる（2025・2026年は投高打低） | 防御率・打率の見た目（村上頌樹 1点台など） | 中 | 年ごとの基準の表が要る。2027年以降は2026年のまま |
| **D. 直近の年を重くする** | `SEASON_WEIGHTS` を 1.0/0.8/0.6 → 例 1.0/0.6/0.3 | 化けた年がすぐ出る（佐藤 2025年など） | 中（全年の作り直し） | 予想としては外れやすくなる（1年だけの好不調が大きく出る）。成長の係数も作り直し |
| **E. 100の頭打ちを緩める** | 1〜100 の上限を外すか、上位を圧縮して差を残す（例：z＞2 は 90＋5×(z−2) で 100 付近に詰める） | 村上・佐藤・近藤などの最上位の差 | 小〜中 | 画面のランク表示（S の上限）、能力値を使う式（年俸・FA）が少し動く |
| **F. 資料の直し** | 作業33の資料の「能力」を開幕の能力値にする、10回の平均を出す | 読み違い | 小（テストだけ） | なし |

おすすめの順（Claude の案）：**B と B'（位置のずれ）→ A'（守備の評価）→ C（試合の係数）**。外部の指標と比べると、npb.jp の数字だけでは範囲がほとんど作れない（A の効きは限定的）ので、守備の評価そのものを直すには A' が要る。B・B' は npb.jp の数字だけでできて、清宮の二塁・中村奨成の捕手・近藤の中堅のような目立つずれはこれで直る。C は佐藤輝明のような強打者の「強さの感じ」に効くが、リーグ全体の調整が要るので別にする。D・E は好み（予想らしさを取るか、その年らしさを取るか）なので、ユーザーに選んでもらいたい。
