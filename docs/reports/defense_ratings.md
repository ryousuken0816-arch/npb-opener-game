# 守備能力値の再構築レポート（npbbasement データ統合）

## 1. 概要と背景

従来の守備能力値算出（`tools/compute_ratings.py`）では、npb.jp 公式記録の「刺殺・補殺・失策」から回帰式によって守備力・肩力を推定していたため、実態や野球界での評判と乖離するケースが存在していました。
- **牧 秀悟（DeNA）**: 失策数の多さから二塁守備が F39 / E49 と極端に低く評価されていた（実際は守備範囲が広くレギュラー水準）。
- **中山 礼都（巨人）**: 外野出場52試合での補殺6から肩力 S100 / A86 と過大評価されていた。
- **近藤 健介（ソフトバンク）**: 左翼守備の名手・強肩であるにもかかわらず守備Cと低めに留まっていた。
- **辰己 涼介 / 岡林 勇希**: 外野刺殺数の多さから守備 S95 / A89 など過剰にインフレしていた。

本改修では、`https://npbbasement.com/` が集計・公開しているトラッキングベースの守備指標（2020〜2026年、1軍および2軍）を取り入れ、守備範囲（RngR）、送球・肩（ARM）、失策抑止（ErrR）、併殺完成（DPR）、捕手フレーミング（Framing）・ブロッキング（Blocking）を能力値の材料として再構築しました。

---

## 2. 実装仕様と算出手法

### 2.1 データ取得と管理
- **スクリプト**: `tools/fetch_basement.py`
- **対象期間**: 2020〜2026年（2020年は1軍のみ、2021〜2026年は1軍および2軍）
- **保存先**: `data/basement/<year>_<1g|2g>.json`
- **リポジトリ管理**: `.gitignore` に `data/basement/` を追加し、取得データはコミット対象外としています。

### 2.2 指標の構成
各指標は得点換算（RUNS）値であり、1000イニングあたりの得点率（rate1000）を算出して評価します。

| ポジション | 守備力（defense）の構成 | 肩力（arm）の構成 |
|---|---|---|
| **一塁手** | `RngR + ErrR + DPR` | - |
| **二塁手** | `RngR + ErrR + DPR` | - |
| **三塁手** | `RngR + ErrR + DPR` | 外野守備 ARM（外野守備がない場合は補殺/試合） |
| **遊撃手** | `RngR + ErrR + DPR` | 外野守備 ARM（外野守備がない場合は補殺/試合） |
| **外野手** | `RngR + ErrR` | `ARM` |
| **捕手** | `Framing + Blocking + ErrR + ARM`（総合守備得点） | `ARM` |

### 2.3 3年加重平均とサンプルサイズ補正
- **直近3年の加重**: 直近シーズンから順に `1.0 : 0.8 : 0.6` で重み付け。
- **2軍データの活用**: 2軍データは重み `0.5` として合算（1軍実績が少ない若手選手の補完）。
- **規定イニングによる縮約（ベイジアン・シュリンク）**:
  - 規定イニング基準：一塁 600回、二塁 700回、三塁 700回、遊撃 700回、外野 800回、捕手 600回。
  - サンプル重み $w = \min(1.0, \frac{\text{合算イニング}}{\text{規定イニング}})$
  - 補正得点率：$\text{blended\_rate} = \text{rate1000} \times w + 0.0 \times (1 - w)$
  - イニングが少ない選手は、過剰な上振れ・下振れを起こさず、ポジションの平均値（0.0）に滑らかに回帰します。

### 2.4 年代間接続（2019年と2020年の目盛り合わせ）
2008〜2019年は npbbasement にデータが存在しないため、従来の npb.jp 公式記録方式を維持しています。
2020〜2025年の重複期間において、新旧方式の平均値・標準偏差が一致するように標準化パラメータ（$\mu=63, \sigma=17$）をキャリブレーションしました。

- **2019_post（旧方式最終年）**: 平均 63.59, 標準偏差 13.07, 中央値 63.00
- **2020_post（新方式開始年）**: 平均 63.96, 標準偏差 11.12, 中央値 64.00

この調整により、2019年と2020年の境目で選手の能力値が段差なく自然に接続されます。
