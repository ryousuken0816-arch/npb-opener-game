# アマ選手の情報（data/amateur/）

ドラフト候補・新人の、公開されている野球の情報（docs/AUTORUN.md 作業16・17）。ウェブ検索（報道・野球専門サイト・
ウィキペディア・ドラフト候補の一覧など）で集め、選手ごとに出典 URL を残している。私生活の情報は入れない。
記事の文章は写さず、評価・紹介文は短く要約したもの。

| ファイル | 中身 |
|---|---|
| `2026.json` | 2026年秋のドラフトで指名された選手（本指名76人・育成51人。npb.jp の指名一覧＝`data/2027/drafts.json` と同じ順） |
| `2027.json` | 2027年秋のドラフト候補（2026年度に高校2年・大学3年の選手、社会人・独立リーグの選手）。史実の指名は無いので、ゲームのドラフトの候補そのもの |

## 形式

```json
{
  "draft_year": 2027,
  "collected": "2026-11-01",
  "note": "...",
  "players": [
    {
      "name": "川本 晴大",            // 姓と名の間に半角スペース（npb.jp の表記に合わせる）
      "team": "読売ジャイアンツ",      // 2026.json のみ：指名した球団（npb.jp の表記）
      "round": "1位",                  // 2026.json のみ："1位"・"育成1位" など
      "school": "大阪桐蔭高",          // 学校・所属（高校は「〇〇高」）
      "category": "高校",              // 高校 / 大学 / 社会人 / 独立 / その他
      "grade": "2年",                  // 2026年度の学年。社会人・独立は "入社3年目" など。分からなければ null
      "birth_year": null,              // 生まれた年（公開されていれば）。月日は入れない
      "pos": "投手",                   // 投手 / 捕手 / 内野手 / 外野手
      "pos_detail": "先発",            // 具体的な守備位置・役割（分かれば）
      "throws": "左", "bats": "左",    // 右 / 左 / 両
      "height": 192, "weight": 95,     // cm / kg
      "max_kmh": 154,                  // 投手の最速（km/h）
      "long_throw_m": null,            // 遠投（m）
      "dash50_s": null,                // 50m走（秒）
      "other_numbers": "...",          // ほかの目立つ数字（自由記述）
      "highlights": ["..."],           // 主な大会の成績
      "evaluation": "...",             // 報道での評価の要約（一文）
      "eval_rank": "S",                // 報道での評価の高さ（下の物差し）
      "projected": "1位候補",          // 2027.json のみ：1位候補 / 上位候補 / 中位〜下位 / 育成候補
      "intro": "大阪桐蔭高の左腕、最速154km",  // ドラフト画面の紹介文（30字以内）
      "scout": {                       // 有識者の評価のまとめ（ユーザー指示 2026-11-01：能力は成績より有識者の評価で決める）
        "strengths": ["..."],          // 長所
        "weaknesses": ["..."],         // 短所
        "grade": "S",                  // 複数の評価を総合した格付け（eval_rank と同じ物差し）
        "type": "大型本格派左腕",
        "comments": [{"by": "...", "summary": "...", "url": "https://..."}]  // スカウト・評論家・専門誌・スポーツ紙の評価の要約
      },
      "sources": ["https://..."],      // 出典（1つ以上）
      "fictional": false               // true＝架空の選手（実在の候補が足りない分の穴埋め。2027.json のみ）
    }
  ]
}
```

格付け（`eval_rank`・`scout.grade`）の物差し：S＝複数球団の1位競合が見込まれる目玉／A＝1位候補／B＝2〜3位級／
C＝4位〜下位／D＝育成〜下位。分からない項目は null（推測で埋めない）。

## 使い道

- **初期能力**：`tools/amateur_ratings.py`（tools/README.md「アマ選手の初期能力」）。`scout.grade` で順位の帯を決め、
  既存の新人の初期能力（区分＋順位）を下地に、長所・短所の言葉で個別の能力を上下する。最速・50m走・遠投は補助
  - 2026.json → `generated/ratings/2027_pre.json` の2026年秋の新人（`amateur_ratings.py rookies --draft-year 2026`）
  - 2027.json → `generated/ratings/2028_pre.json` のドラフト候補（`amateur_ratings.py carry --year 2027`）
- **当時の評価**：2026年は史実の指名順位と1位の競合（`data/draft_first_round.json`）、2027年は `scout.grade`
  （`Draft.GRADE_AS_PICK`）
- **紹介文**：ドラフト画面の候補の要約に `intro` を表示（`Draft._fill_profile`）
- 作業21（アマ時代の活躍ニュース）でも `highlights` などを使う予定
