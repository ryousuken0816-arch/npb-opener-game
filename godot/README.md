# godot/ — ゲーム本体（Godot 4.7）

Godot エディタで `godot/project.godot` を開いて実行（F5）。タイトル → 球団選択 → ハブ画面。

## 構成

| パス | 役割 |
|---|---|
| `autoload/game_data.gd` (`GameData`) | 能力値JSON・史実の日程（`load_schedule()`）の読み込み・球団別の選手一覧・球団略称・ランク色 |
| `autoload/game_state.gd` (`GameState`) | 年・今日の日付（`day`）・フェーズ・自球団と、その年のペナント（`season: Season`）。日単位の進行と早送り（`start_fast_forward()` / `stop_fast_forward()`）、可変ボタンの文言と進行（`advance()`＝1か月）。順位表は `standings()` |
| `sim/season.gd` (`Season`) | 1年分のペナント。史実の日程の status=played の試合を日付順にシミュレーションし、全試合の結果（スコア・イニング別得点・勝敗セーブ投手・個人成績）と球団成績・個人通算成績を保持 |
| `sim/game_sim.gd` (`GameSim`) | 1試合のシミュレーション（打席単位、docs/SPEC.md の8段階）。係数は冒頭の定数 |
| `sim/sim_team.gd` (`SimTeam`) | 球団の編成：1軍登録（試合に出るのは1軍だけ）、スタメン・打順（DHあり/なし）と控え、先発6人ローテ・中継ぎ（先頭2人がセットアッパー）・抑え、采配方針（`tactics`）。投手の登板間隔。開幕時に自動編成（CPU球団はそのまま）、自球団は采配画面から書き換える |
| `sim/roster_rules.gd` (`RosterRules`) | 1軍登録の史実のルール：登録人数の上限（2008〜18年28人・2019年〜29人・2020〜21年31人）、外国人枠（4人・投手野手とも3人まで、2020〜21年は5人）、抹消後10日間の再登録不可、外国人の判定（ドラフト歴なし＋経歴あり、在籍8年以上は日本人扱い） |

| `tests/ui_capture.gd` | 球団を選んで、日程表で早送り→中止→1日→1週間、そのあと月を進めながら、ハブ・日程表・采配のスクショを保存（見た目の確認用） |
| `tests/tactics_check.gd` | 采配の確認（ヘッドレス）。全球団の1軍が上限・外国人枠を守る／上限・外国人枠・10日ルールを超える登録を断る／2軍から上げてスタメン・先発ローテに入れた選手が数日で試合に出て成績が付き、落とした選手は出ない（毎日、出場選手が全員1軍か調べる）／采配方針が犠打・盗塁・先発の投球回に効く |
| `tests/tactics_capture.gd` | 采配画面のスクショ（一覧→投手・野手1軍登録で入れ替え→起用設定→思考設定→日程表で2週間進めて成績が付いた画面） |
| `tests/day_progress_check.gd` | 日単位の進行の確認（ヘッドレス）。日付指定の早送り→中止→1日ずつ→1週間→試合へ→最終日まで早送りしてオフ→翌年。各段階で「今日より前の試合だけ終了」「順位表の勝敗合計＝試合数」「個人成績の打席合計＝試合の打席合計」を調べる |
| `scenes/title/` | ニューゲーム（2008年開幕の球団選択。球団ボタンは各球団のチームカラー） |
| `scenes/hub/hub.tscn` | ハブ画面（パワプロのペナント画面風。docs/references/README.md）。左に大きなメニュー、上にイベント名、右上に順位表、下に説明文と日付。メニューを押すと中央〜右に各画面を開く（Esc で戻る） |
| `scenes/hub/hub_menu_button.gd` | メニューボタン（アイコン＋太字、ボタンごとの色。選択中は大きく・右へせり出す） |

## 配色

- 球団カラーは `GameData.TEAM_COLORS`（[メイン, サブ]）。`UiTheme.team_palette(球団名)` で背景・パネル・見出し・順位表などの色を作る
- 背景は白寄りの明るい色（メインカラーを薄めたもの）。黒基調にはしない
- メニューボタンは参考画像にならってボタンごとに固定色（試合へ=赤、日程表=ピンク、采配=橙、新戦力=緑、記録室=黄、システム=紫）

## 能力値データの場所

`GameData` は次の順に `<年>_<pre|post>.json` を探す。

1. `res://data/ratings/`（書き出し用。未作成）
2. リポジトリ直下の `generated/ratings/`（エディタ実行時はこちらを直接読むのでコピー不要）

書き出し（エクスポート）する段階で 1 へのコピー手順を用意する。

## フェーズ進行（可変ボタン）

シーズンは**日単位**で進む。`GameState.day` は「今日」（まだ試合をしていない日）の通し日数（`Season.day_number`）で、
開幕日から始まり、1日進めるとその日の全カードをシミュレーションして翌日になる。

- 日程表の「1日進める」「1週間進める」「この日まで早送り」→ `GameState.start_fast_forward(目標日)`。`_process()` が
  `FAST_FORWARD_INTERVAL`（0.12秒）ごとに1日進め、目標日の試合が終わったら止まる。`stop_fast_forward()` で途中で止める
  （日程表を閉じたとき・ハブの「試合へ」を押したときも止まる）
- ハブの「試合へ」（`advance()`）は近道：今月の残り日程をまとめて行い、翌月1日へ（最終月ならシーズン終了へ）
- 月が替わると `GameState.month_started` を出す。SPEC の「月ごとの粒度」（故障・トレードイベント、育成コマンド）はここに挟む（未実装）
- シーズンの期間は開幕日〜最終試合日（2008年は3/20〜10/12）。日程データ（`data/<年>/schedule.json`）が無い年は
  4/1〜10/31 を試合なしで進む（`GameState.season` は null）

最終日を終えると オフ へ進み、ボタンは次のフェーズ名に切り替わる：

シーズン終了・表彰 → 現役ドラフト（2022年オフ以降のみ）→ FA・トレード・ポスティング → 契約更改 → 戦力外・引退 → ドラフト → 春季キャンプ（翌年） → 開幕

- 表彰に入ると当年の `post` 能力値、春季キャンプで翌年の `pre` 能力値に切り替える（ファイルがなければ現状維持）

## 未実装（プレースホルダー）

采配の練習設定・登録設定・情報と対左投手用オーダー、新戦力・記録室・システム、各フェーズの画面、選手詳細、
試合結果画面（ハイライト・勝敗確率グラフ）。
試合結果・成績はメモリ上（`GameState.season`）にあり、セーブ/ロードは未実装。
故障・疲労による休養はなく、スタメンは自球団が変えない限り固定（DH制の有無で2通り）。CPU球団は開幕時の自動編成のまま。

## メモ

- 日本語フォントは同梱の M PLUS Rounded 1c。一部の人名漢字（燁・嵜・邉 など）は含まれないため OS のフォント（Yu Gothic UI 等）で表示される
- クラウド環境でも GitHub Releases から Godot 4.7（Linux 版）を取得でき、`xvfb-run` で起動してスクリーンショットを確認できる。GDScript は `gdlint` でもチェックしている
  - 例：`xvfb-run -a godot --path godot --resolution 1280x720 --script res://tests/ui_capture.gd -- <出力先> 阪神タイガース`（初回は先に `godot --headless --path godot --import`）

## 試合シミュレーション（`sim/`）

- 能力値は `z = (値 − 63) / 17`（`tools/README.md` のスケールの逆）に直し、各確率を「基準値のロジット＋係数×z」のシグモイドで出す
- 打席の流れ：死球 → 四球（選球眼×制球）→ 三振（ミート×奪三振）→ 本塁打（パワー・弾道×被弾抑制）→ 打球の質（ミート・パワー×総合力）→
  凡打球（内野の守備力でアウト/内野安打、アウトは失策判定、併殺）／鋭い当たり（外野の守備力で安打・長打を抑え、肩で進塁を阻止）
- 走塁は走力と外野の肩で一塁→三塁・二塁→本塁・二塁打で一塁→本塁と憤死を判定。盗塁は走力で企図、走力と捕手の肩で成否
- 試合に出るのは1軍（`SimTeam.active`）の選手だけ。代打は1軍の控えから
- 采配方針（`SimTeam.tactics`、−2〜+2。自球団は思考設定、CPUは0）：送りバントの頻度と対象、盗塁の企図率、先発を代える球数の目安が変わる（係数は `game_sim.gd` の `*_TACTIC_*`）
- 采配：投手の打順・打力の低い打者は無死一塁/二塁で送りバント、DHなしの終盤は投手に代打。先発は目安の球数（スタミナ）＋5球・5失点で交代、
  7〜9回の僅差リードはセットアッパー2人→抑えの順。リリーフは前日35球超・3連投になる日は休み
- 疲労：目安の球数を超えると15球ごとに z −0.45。先発は中5日以上あける6人ローテ
- 勝敗投手：最後に勝ち越したときの投手が勝利（先発は5回以上）、その走者の責任投手が敗戦。セーブ・ホールドは簡易判定
- 延長は12回まで（引き分けあり）。パ・リーグ主催試合（交流戦含む）はDH制

### 係数の調整

```
godot --headless --path godot --script res://tests/season_check.gd -- 2008 [シード]
```

2008年の開幕時能力値で全864試合を回し（約2秒）、リーグ全体の打率・本塁打・防御率・得点などを
`data/2008/teamstats_linked.json` の1軍成績と並べて表示する。係数を変えたらシードを変えて数回回して確認する。
10シードの平均（2026-09-25 調整時）：打率 .266（史実 .265）、本塁打 1472（1480）、防御率 3.76（3.83）、
1チーム1試合の得点 4.10（4.14）、勝率の標準偏差 .073（.064）。
